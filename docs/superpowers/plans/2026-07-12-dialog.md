# NibDialog / Modal Implementation Plan

> **Direct-implementation note:** per this repo's `CLAUDE.md`, components are built
> directly in the main session with TDD (failing test → impl → pass), **not** via the
> subagent/executing-plans flow. This doc is the design of record + task checklist;
> it is not handed to an implementer subagent.

**Goal:** Ship the Dialog / Modal component (Tier A #8) — a native, focus-trapping,
stackable modal with two public faces built on one primitive: an imperative
`showNibDialog<T>()` returning a result `Future`, and a declarative `NibDialog` widget
matching the house style of `NibSelect`/`NibDatePicker`.

**Foundation (locked in brainstorming):** raw `Overlay` (like every existing overlay
component) + manual focus trap + `nib_motion` enter/exit — **not** Flutter
`Navigator`/`ModalRoute`. Keeps the §1.4 animation contract and the codebase's overlay
lifecycle consistent; the one genuinely-new bit is the focus trap.

**Tech:** Flutter/Dart stable, `nib_motion` path dep (already wired). No new pub deps.

## Global constraints (master prompt §1, §2)

- Public widgets `Nib`-prefixed PascalCase. No hardcoded hex — colors/radii via
  `NibTheme.of(context)`. **One documented exception:** the barrier scrim
  (`Colors.black` @ ~45%), overridable via `barrierColor` — a scrim is a semantic dim,
  not a themed surface; existing Select/DatePicker modals ship no scrim, Dialog needs one.
- Simple by default (§1.2): `showNibDialog(context, title: '…', content: …)` and
  `NibDialog(trigger: …, content: …)` must both render a finished modal; every other
  param optional. `content`/`footer`/`header` are plain `Widget`s — descendants close
  with a result via `NibDialogScope.of(context).close(result)`.
- Stateful by default (§1.3): `NibDialog` owns its `NibDialogController` when none passed,
  disposes it on unmount/swap. Modal children keep their own state (barrier/card are the
  only rebuilds; descendant `setState` is never swallowed).
- Animated opt-in (§1.4): `animated:false` builds **zero** `NibMotion` widgets (instant
  mount/unmount, no scrim fade). `animated:true` routes enter/exit through
  `NibMotion`/`NibPresence` (same exit-timer estimate pattern as `NibSelect`).
- Responsive (§1.7): dialog width clamps to `viewport.width − 2·margin`; content scrolls
  vertically when it overflows; tested at a narrow and a wide viewport.

## Public API (barrel exports)

`showNibDialog`, `NibDialog`, `NibDialogController`, `NibDialogHandle`,
`NibDialogScope`, `NibDialogSize`, `NibDialogAnimation`.

```dart
Future<T?> showNibDialog<T>(
  BuildContext context, {
  String? title,
  String? description,
  Widget? header,                       // full override of default title/description/close-X
  required Widget content,
  Widget? footer,
  NibDialogSize size = NibDialogSize.md,
  double? width,                        // custom-size escape hatch (overrides size)
  bool barrierDismissible = true,
  bool showCloseButton = true,
  Color? barrierColor,                  // default Colors.black @ ~.45
  bool animated = false,
  NibDialogAnimation animation = NibDialogAnimation.fadeScale,
  NibTransition? transition,
  VoidCallback? onClose,
});
```

`NibDialog` (declarative) mirrors those params plus `Widget? trigger`,
`NibDialogController? controller`. On open it delegates to the same primitive.

**One primitive, two faces:** internal `NibDialogHandle openNibDialog(...)` does the work
(overlay insert, barrier, focus trap, animated card, stack push) and returns a handle
(`Future<T?> closed`, `void close([Object? result])`, `bool isOpen`).
`showNibDialog` = `openNibDialog(...).closed`; `NibDialog` holds the handle and closes it
when its controller flips.

## Files

- `lib/src/dialog/nib_dialog_types.dart` — `NibDialogSize {sm,md,lg,fullscreen}`,
  `NibDialogAnimation {none,fade,scale,fadeScale,slideUp}`, pure
  `double? nibDialogMaxWidth(NibDialogSize)` (sm 380 / md 512 / lg 720 / fullscreen null),
  and `NibAnim resolveNibDialogEnter(NibDialogAnimation)`.
- `lib/src/dialog/nib_dialog_controller.dart` — `NibDialogController extends ChangeNotifier`.
- `lib/src/dialog/nib_dialog_surface.dart` — internal `_NibDialogSurface` stateful widget:
  barrier + `NibDialogScope` (InheritedWidget exposing the handle) + focus trap + animated
  card (header / `Flexible(SingleChildScrollView(content))` / footer). Shared surface.
- `lib/src/dialog/show_nib_dialog.dart` — `openNibDialog`, `showNibDialog`, top-level
  `_dialogStack` registry (Escape/back close topmost; restore `primaryFocus` on close).
- `lib/src/dialog/nib_dialog.dart` — declarative `NibDialog` widget.

## Behavior details

- **Barrier** — full-screen opaque `GestureDetector`; tap closes only if
  `barrierDismissible`. Scrim fades with the card when `animated`.
- **Focus trap** — card in `FocusScope`(autofocus) + `FocusTraversalGroup`; Tab / Shift+Tab
  overridden to scope `nextFocus()`/`previousFocus()` → wraps inside the dialog.
  `BlockSemantics` + `Semantics(scopesRoute, namesRoute: title, explicitChildNodes)`.
  Capture `FocusManager.instance.primaryFocus` on open, restore on close.
- **Stacking** — `_dialogStack` list; each show pushes an `OverlayEntry` (natural z-order)
  with its own barrier + Escape; topmost holds focus so Escape / outside-tap closes only
  it. Dialog-from-dialog works.
- **Sizing** — `width ?? nibDialogMaxWidth(size)`, clamped to viewport − margin. Fullscreen
  fills via `SafeArea` (no maxWidth).
- **Animation presets** — none identity / fade op0 / scale 0.96 / fadeScale op0+0.97
  (default) / slideUp op0+y16.

## Known-gap parity (carry forward, don't re-solve)

- Animated exit unmounts on a `transition.duration`+buffer **estimate** (springs ~450ms),
  same as `NibSelect` — a true `NibPresence` completion signal is the deferred refinement
  already tracked for Select.
- Focus trap covers Tab cycling; no roving-arrow inside the dialog (not required by spec) —
  consistent with the Data Table / Date Picker traversal calls.
