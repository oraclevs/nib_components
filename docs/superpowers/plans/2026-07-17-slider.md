# NibSlider — design & build plan (2026-07-17)

Component #19 (Tier B). Spec source: `NIB_COMPONENTS_MASTER_PROMPT.md` §6 row 19
(range mode / two thumbs, tick marks, value label on drag) + the §1 architecture
rules. User-approved brainstorm decisions (2026-07-17):

1. **Single + range now** — one widget/paint/gesture core, `NibSlider.range` named
   constructor gives the second thumb. Not deferred (a later 2nd-thumb retrofit of
   the track/gesture paint is real rework).
2. **Horizontal + vertical** — `axis: Axis` param. Main-axis math flips for vertical
   (min at the bottom).
3. **nib_motion opt-in = thumb press-pop + value-label fade.** Core drag / track-fill
   always follow the finger 1:1; `animated:false` builds **zero** `NibMotion`.

## Public API

```dart
// single (controlled, Material-familiar)
NibSlider({
  required double value,
  ValueChanged<double>? onChanged,          // null ⇒ disabled
  ValueChanged<double>? onChangeStart,
  ValueChanged<double>? onChangeEnd,
  double min = 0, double max = 1,
  int? divisions,                            // snap + tick marks
  bool showValueLabel = false,
  String Function(double)? valueLabelFormatter,
  Axis axis = Axis.horizontal,
  bool disabled = false,
  // customization (memory: component-customization-mandate — geometry escape hatches)
  double? trackHeight,                       // default 4
  double? thumbSize,                         // default 20
  Color? activeColor, inactiveColor, thumbColor, tickColor,
  BorderRadiusGeometry? trackRadius,         // default pill
  EdgeInsetsGeometry? padding,
  NibSliderThumbBuilder? thumbBuilder,       // full thumb escape hatch
  // motion (repo uses transition:, NOT §4's `animation` — Button precedent/gap)
  bool animated = false,
  NibTransition? transition,
  // a11y
  String? label, FocusNode? focusNode, bool autofocus = false,
})

// range — two thumbs sharing the same core; thumbs clamp at each other (no cross)
NibSlider.range({
  required NibRangeValues values,
  ValueChanged<NibRangeValues>? onChanged,
  ValueChanged<NibRangeValues>? onChangeStart, onChangeEnd,
  ... same rest ...
})
```

### Types (`nib_slider_types.dart`)
- `NibRangeValues { double start, end; clamp(min,max); copyWith; ==/hashCode }`
  (own type, Nib-prefixed, self-contained — not Material's `RangeValues`).
- `typedef NibSliderThumbBuilder = Widget Function(BuildContext, NibSliderThumbState)`
  with `NibSliderThumbState { double value; bool dragging, focused; double size }`.

## Architecture (§1.1 build native, not wrapped)

- `LayoutBuilder` resolves the main-axis extent; the track is inset by the thumb
  radius so a thumb centre travels `[r, extent-r]` and never clips at the ends.
- `CustomPaint` paints **track + active fill + tick marks** (one painter, repaints
  on value/drag only).
- **Thumbs are widget-layer children** (`Positioned` in a `Stack`), so `thumbBuilder`,
  the focus ring, and the `nib_motion` press-pop all work at the widget layer.
- Gesture: **axis-specific** drag recognizer (`onHorizontalDrag*` for
  `Axis.horizontal`, `onVerticalDrag*` for vertical) so the gesture arena resolves
  correctly against an orthogonal parent scrollable, **plus** `onTapDown` tap-to-seek.
  Range: drag start picks the nearest thumb; the moving thumb clamps against the other.
- Vertical: min at the **bottom** (`fraction = 1 - localY/extent`).
- Keyboard: each thumb is a `Focus` (single slider → 1, range → 2, giving free Tab
  traversal). `onKeyEvent` handles ←/→ (horizontal) or ↑/↓ (vertical) = ±1 step
  (`divisions` step, else `(max-min)/100`), Home/End = min/max. Focus paints
  `theme.ring`.
- `Semantics(slider: true, value:, increasedValue:, decreasedValue:, onIncrease:,
  onDecrease:, label:)` per thumb.

## State (§1.3)

Value is **controlled** via `value`/`onChanged` (single) / `values`/`onChanged`
(range) — that pair *is* the control surface, so there is **no separate
`NibSliderController`** (deliberate: unlike open/close/selection components, a
slider's entire state is its value, already externally owned). The private `State`
holds only transient drag/press/focus + the active-thumb index.

## Value label (memory: component-customization-mandate — no resize on state)

When `showValueLabel:true`, a **constant** label lane is reserved above the track —
the box height never changes between idle and dragging. The bubble (rounded, `card`
bg, value text via `valueLabelFormatter`) fades/scales in on grab via `NibMotion`
when `animated:true`, or appears instantly when `animated:false`.

## Motion contract (§1.4)

- grab → thumb `NibMotion(animate: NibAnim(scale: 1.3))`, release → `NibAnim.identity`
  (grows while held), driven by `transition` (default ~120ms ease).
- label bubble → `NibMotion` fade+scale in.
- `animated:false` → **zero** `NibMotion` widgets; track-fill/drag/tap/keyboard all
  still work (feedback is native, not motion). Verified `find.byType(NibMotion),
  findsNothing`.

## Tokens (§2, `NibTheme.of`)

active = `primary`, inactive = `border`, thumb fill = `primary` with a `background`
ring, tick = `mutedForeground`, focus ring = `ring`, label bubble = `card` /
`cardForeground`. Disabled dims to 0.5. Track radius = pill by default.
`trackHeight` 4, `thumbSize` 20; cross-axis box ≥ 48 (tap target) via padding, not
by resizing the thumb.

## Tests (§1.6 evidence)

`test/slider/nib_slider_test.dart`: default render + fill proportion · each axis ·
range 2-thumb + no-cross clamp · `divisions` snapping · drag updates `onChanged`
(start/end callbacks) · tap-to-seek · keyboard ±/Home/End · `disabled`/null-onChanged
inert · `showValueLabel` bubble present · `animated:true` builds `NibMotion` /
`animated:false` → `findsNothing` · custom colors/thumbSize applied · narrow-width no
overflow (`takeException` null). Plus `NibRangeValues` unit tests (clamp/copyWith/==).

## Output contract (§1.5)

`example/lib/examples/slider_examples.dart`: (1) minimal single · (2) divisions +
value label · (3) advanced: range + vertical + custom colors + animated · registered
in `example/lib/catalog.dart` after the Button entries.
