# Toast — design & plan (2026-07-16)

Component #17 (Tier B). An imperative toast/notification service with **ID-based
de-duplication** (the master-prompt headline), stacking, six positions, variants,
an action button, a close button, and swipe-to-dismiss.

## Nature: imperative service, not a widget

Like `showNibDialog`/`showNibBottomSheet`, toasts are ephemeral and fire-and-forget
— there is no declarative `NibToast` widget and no per-instance controller. A
global `_NibToastManager` owns state; a single lazily-inserted host `OverlayEntry`
(root overlay) renders everything. No wrapper widget is required in the app.

## Public API

```dart
String showNibToast(BuildContext context, {
  String? id,                    // dedup key; null → a unique id (never dedups)
  String? title,
  String? message,               // description line
  Widget? content,               // custom body; overrides title/message
  NibToastVariant variant = NibToastVariant.normal,
  IconData? icon,                // override the variant's icon
  NibToastPosition position = NibToastPosition.bottomRight,
  Duration duration = const Duration(seconds: 4), // Duration.zero → persistent
  String? actionLabel,
  VoidCallback? onAction,
  bool showCloseButton = true,
  bool dismissible = true,       // swipe-to-dismiss
  NibToastDuplicateBehavior onDuplicateTrigger = NibToastDuplicateBehavior.shake,
  bool animated = false,         // framework convention; demos pass true
  NibTransition? transition,
  VoidCallback? onDismiss,
});                              // returns the (resolved) id

void dismissNibToast(String id);
void dismissAllNibToasts();
```

- `NibToastVariant { normal, success, error, warning, info }` — each maps to an
  icon + accent from `NibTheme` (success→green-ish/primary, error→destructive,
  warning→amber, info→accent, normal→foreground/muted). `icon` overrides.
- `NibToastPosition { topLeft, topCenter, topRight, bottomLeft, bottomCenter,
  bottomRight }` — default `bottomRight`. Each position is its own independent stack.
- `NibToastDuplicateBehavior { shake, ignore, replace }` — default `shake`.

## Manager (`_NibToastManager` — singleton `ChangeNotifier`)

- Holds `List<_ToastData>` (id, position, spec fields, a per-item bump counter for
  shake, and a "dismissing" flag).
- Captures the root `OverlayEntry`/`OverlayState` from the first `showNibToast`
  call's context; inserts the host entry on first toast, removes it when the list
  empties.
- `show`: resolve id (auto-unique if null). If an active toast has that id →
  apply `onDuplicateTrigger`: `shake` (bump the existing item's shake counter →
  it wobbles, and reset its timer), `ignore` (no-op), `replace` (swap its fields +
  reset timer). Else append a new `_ToastData`; if the position's visible count
  now exceeds `maxVisible` (5), dismiss the **oldest** at that position (FIFO).
  Start the auto-dismiss `Timer` unless `duration == Duration.zero`.
- `dismiss(id)`: mark dismissing → the item plays its exit (slide+fade + height
  collapse) → a duration-estimate `Timer` removes it from the list → `onDismiss`.

## Host + item

- `_NibToastHost` (listens to the manager): a full-screen `Stack`; for each of the
  6 positions that currently has toasts, a `Positioned.fill` → `SafeArea` →
  `Align(position)` → `Column(mainAxisSize.min)` of that position's items. Newest
  nearest the anchor edge (bottom positions reverse the column so the newest is at
  the bottom; top positions keep natural order). Responsive item width
  `min(360, screenWidth − 2*margin)` (§1.7).
- `_NibToastItem` (StatefulWidget): the card + interactions.
  - **Enter/exit slide+fade** → `NibMotion`/`NibPresence` when `animated`
    (Toast's §1.4 default). Slide direction is inferred from the position (from
    the nearest edge). `animated:false` → instant, **zero `NibMotion`** (tested).
  - **Height-collapse reflow**: on exit an `AnimationController` shrinks the item
    height (ClipRect + Align heightFactor, Accordion precedent) so neighbors slide.
  - **Shake**: an `AnimationController` plays a decaying horizontal wobble when the
    manager bumps this item's shake counter (`didUpdateWidget` detects the bump).
    Gesture/anim-driven → works even when `animated:false` (it's feedback).
  - **Swipe-to-dismiss** (`dismissible`): `onHorizontalDragUpdate` translates the
    card; past a threshold/velocity on release → dismiss; else spring back
    (`AnimationController`).
  - Card: leading variant icon, title (w600) + message (muted), optional action
    `NibButton`-style text button, optional close (×). Colors/radii from
    `NibTheme`. Light+dark for free.

## Tests (TDD)

1. `showNibToast` inserts a toast (title/message found in the overlay).
2. Auto-dismisses after `duration` (pump past it → gone); `Duration.zero` persists.
3. Dedup: same `id` + `shake` → still exactly **one** toast with that id (+ timer
   reset). `ignore` → one, content unchanged. `replace` → one, content swapped.
4. Close (×) dismisses; `onDismiss` fires.
5. Swipe past threshold dismisses; short swipe springs back (stays).
6. Action button fires `onAction`.
7. Each variant renders its icon.
8. Two different ids → two toasts stacked at the position.
9. `maxVisible` exceeded → oldest at that position removed (FIFO).
10. `dismissNibToast(id)` removes one; `dismissAllNibToasts` clears all.
11. `animated:true` builds `NibMotion`; `animated:false` builds none.
12. `position` places the stack at the correct `Alignment`.

## Example demos

- **Trigger board** — buttons firing each variant at assorted positions.
- **Dedup** — a "Save" button that, spammed, shakes the one toast instead of
  stacking; toggle shake/ignore/replace.
- **Action + persistent** — an "Undo" toast with `duration: Duration.zero` and an
  action callback.
- **Stack + swipe** — fire several to show stacking, reflow on dismiss, and
  swipe-to-dismiss.

## Known-gap candidates (log if hit)

- Exit removal uses a duration-**estimate** `Timer` (no true `NibPresence`
  completion signal) — identical mechanism/caveat as Dialog/Select/Popover.
- Smooth height-collapse reflow: if it proves disproportionate, fall back to
  `NibPresence`-only (instant reflow) and log it.
- `maxVisible` overflow is FIFO-dismiss (not a queue that re-shows later).

## Post-review additions (2026-07-17)

Feedback after the first visual pass:

- **Context-free API.** `showNibToast`'s `context` is now an optional named param.
  A `NibToaster` root wrapper (placed via `MaterialApp.builder`) hosts its own
  `Overlay` and registers it with the manager, so `showNibToast(...)` works from
  anywhere (services, blocs, callbacks) with no context — toastify-style. Context
  is only needed as a fallback when no `NibToaster` is mounted.
- **Shaping knobs.** `padding`, `borderRadius`, and `backgroundColor` were added to
  `showNibToast` (and `replace`), useful especially with a custom `content` widget.
- **Custom-content demo** added to the example (`ToastCustomContentExample`).
