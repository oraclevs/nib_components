# Combobox (#5) — implementation plan

Component #5 in the hardest→simplest build order (MASTER_PROMPT §3, spec §5.5).
A combobox is a text field fused with a filtered, keyboard-navigable dropdown of
options, supporting single- and multi-select, free-text vs. selection-only modes,
and both synchronous and async/debounced data sources.

## Why it's hard (from the spec)

Combines three things that each have their own edge cases — a text field, a
filtered overlay list, and keyboard navigation — plus async data loading with an
in-dropdown loading state, and a multi-select variant that renders chips *inside*
the field. The reference bar (§1.1) is Flutter's own `Autocomplete` /
`DropdownButtonFormField` internals.

## Architecture decisions

- **Self-contained field widget, not a wrapper.** Unlike `NibCommandPalette`
  (which wraps the whole app to capture a global shortcut and shows a centered
  modal), `NibCombobox<T>` *is* the input control. It renders a text field
  anchored to its own dropdown. No `child`.

- **Generic over the option value `T`.** Options are `NibComboboxOption<T>`
  (`value`, `label`, optional `subtitle`/`icon`/`disabled`), mirroring
  `NibCommandAction`'s shape. The simple `String` case is
  `NibComboboxOption(value: 'apple', label: 'Apple')`.

- **Own `OverlayEntry`, anchored via `LayerLink` + `CompositedTransformFollower`,
  rebuilt with `markNeedsBuild()`.** The dropdown must rebuild on every keystroke
  / filter / highlight / loading change, and its width must match the field.
  `NibAnchoredOverlay.show()` (used by Navigation Menu) creates an entry it owns
  and measures content's *intrinsic* width — neither fits here — so this manages
  its own entry directly, the same way `NibCommandPalette` does. Flip above the
  field when there isn't room below (heuristic: space-below vs. space-above with a
  capped max height); the list is always a `maxHeight`-bounded scrollable so it
  never overflows (§1.7).

- **Keyboard nav via `Shortcuts`/`Actions` around the field.** Focus stays on the
  field's `EditableText` while the dropdown is open; arrows/enter/escape are
  intercepted before the field (verified during Command Palette that these bubble
  past a focused single-line field). Down opens-or-moves, Up moves, Enter selects
  the highlight (or commits free text), Escape closes.

- **Selection + open + query live on an optional `NibComboboxController<T>`
  (`ChangeNotifier`)**, created internally when none is passed and disposed on
  unmount/swap — same bind/unbind/owns pattern as `NibCommandPaletteController`.
  Highlight index and the debounce timer are transient UI state in the `State`.

- **Async:** two supported styles. (a) built-in `asyncOptionsLoader(query)` with
  `debounceDuration`, a stale-response guard (latest-request wins), and an
  in-dropdown spinner row; (b) consumer-driven `options` + a forced `loading`
  bool. Sync local filtering when neither async path is active.

- **Animation contract (§1.4):** `animated: false` (default) builds zero
  `NibMotion`; `animated: true` wraps the dropdown card in a `NibMotion`
  fade+scale+slide, `transition` overridable — identical to the palette.

## API surface

```dart
NibComboboxOption<T>({ required T value, required String label,
  String? subtitle, Widget? icon, bool disabled = false })

typedef NibComboboxFilter<T> = bool Function(NibComboboxOption<T> option, String query);
typedef NibComboboxOptionsLoader<T> = Future<List<NibComboboxOption<T>>> Function(String query);

NibCombobox<T>({
  List<NibComboboxOption<T>> options = const [],
  NibComboboxOptionsLoader<T>? asyncOptionsLoader,
  bool multiSelect = false,
  bool allowFreeText = false,
  Duration debounceDuration = const Duration(milliseconds: 300),
  ValueChanged<T?>? onChanged,               // single-select convenience
  ValueChanged<List<T>>? onSelectionChanged, // fires in both modes
  ValueChanged<String>? onFreeTextSubmitted, // when allowFreeText commits raw text
  bool loading = false,                      // consumer-forced loading row
  NibComboboxFilter<T>? filter,              // default: case-insensitive substring on label/subtitle
  WidgetBuilder? noResultsBuilder,
  String placeholder = 'Select…',
  bool clearable = true,
  bool disabled = false,
  bool animated = false,
  NibTransition? transition,
  double maxDropdownHeight = 280,
  NibComboboxController<T>? controller,
})

NibComboboxController<T> extends ChangeNotifier {
  List<T> get selectedValues;        // unmodifiable
  T? get selectedValue;              // first or null
  String get query;
  bool get isOpen;
  void open(); void close();
  void selectOnly(T v); void toggle(T v); void clear();
}
```

## Behaviour

- **Selection-only (`allowFreeText: false`, default):** typing filters; the value
  changes only when an option is picked. Closing/blurring without a pick reverts
  the field text to the current selection's label (single) / clears the query
  (multi). Enter with no match is a no-op.
- **Free-text (`allowFreeText: true`):** the typed text is retained; Enter commits
  it via `onFreeTextSubmitted` (kept separate from `T` selection, since raw text
  isn't a `T`). A matching option can still be picked normally.
- **Single-select:** picking sets the selection to `[value]`, puts `label` in the
  field, closes, fires `onChanged(value)` + `onSelectionChanged([value])`.
- **Multi-select:** picking toggles the value, keeps the dropdown open, clears the
  query, renders selected values as removable chips (in a `Wrap`) inside the field;
  fires `onSelectionChanged`. Backspace on an empty query removes the last chip.
- **Clear button:** trailing ✕ (when `clearable` and there's a query or selection)
  clears query + selection and fires the change callbacks.
- **Disabled:** field non-interactive, dropdown never opens, muted styling.

## Files

- `lib/src/combobox/nib_combobox_option.dart` — model + typedefs.
- `lib/src/combobox/nib_combobox_filter.dart` — `defaultComboboxFilter`,

- `lib/src/combobox/nib_combobox.dart` — the widget + private dropdown.
- barrel: export option, controller, widget (not filter).
