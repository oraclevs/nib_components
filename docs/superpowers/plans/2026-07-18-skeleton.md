Use `superpowers:executing-plans` inline, not `subagent-driven-development`, unless the user explicitly asks otherwise.

**Goal:** Build `NibSkeleton`, a wrapper widget that auto-detects a real widget tree's leaf content (Text, Icon, CircleAvatar, Image, boxes) and structure (Row/Column/Padding/etc.), and renders a matching bone/skeleton placeholder while `loading` — with zero hand-rebuilt parallel skeleton tree.

**Architecture:** A pure recursive shading function (`shadeWidget`, in `nib_skeleton_shade.dart`) dispatches on `node.runtimeType` into leaf/structural/auto-expand/fallback buckets, building bone `Widget`s directly from the real node's own constructor params — no `RenderObject`/`Element` introspection, no measure pass. `NibSkeleton` (a `StatelessWidget`, `nib_skeleton.dart`) calls it once per build when `loading: true`, and composes existing `nib_motion` primitives (`NibShimmer` for the sweep, `NibPresence`+`NibMotion` for the opacity dissolve) for the `animated: true` case — no new animation code.

**Tech Stack:** Flutter/Dart, `package:nib_motion` (path dependency, already in `pubspec.yaml`), `flutter_test`.

## Global Constraints

- Colors/radii read from `NibTheme.of(context)` — never hardcoded hex (`CLAUDE.md`, "Every component must").
- Widget class is named `NibSkeleton` (Nib prefix, per naming convention).
- Motion goes exclusively through `nib_motion` widgets (`NibMotion`, `NibShimmer`, `NibPresence`) — never `AnimatedContainer`/`AnimatedSwitcher`/other implicit-animation widgets.
- `animated: false` (default) must build **zero** `NibMotion`/`NibShimmer`/`NibPresence` widgets — verified with `find.byType(...), findsNothing` tests, per the stateful-component pattern's animation contract.

import 'package:flutter/widgets.dart';

/// The bone shape [NibSkeletonBone] paints.
enum NibSkeletonShape {
  /// A rounded rectangle.
  rectangle,

  /// A perfect circle.
  circle,
}

/// An explicit bone-shape override for a spot in [NibSkeleton]'s child tree
/// its automatic detector can't shape correctly (e.g. a custom-painted
/// chart). While the ambient `NibSkeleton` is loading, this renders the
/// given [width]/[height]/[shape] instead of [child]; while not loading, it
/// renders [child] normally — the same "one authored tree" rule every other
/// spot in a `NibSkeleton` follows.
class NibSkeletonBone extends StatelessWidget {
  /// Creates an explicit bone override wrapping [child].
  const NibSkeletonBone({
    super.key,
    required this.child,
    this.width,
    this.height,
    this.shape = NibSkeletonShape.rectangle,
  });

  /// The real widget shown whenever this node isn't being shaded.
  final Widget child;

  /// Bone box width. `null` falls back to the ambient `NibSkeleton`'s
  /// `fallbackWidth`.
  final double? width;

  /// Bone box height. `null` falls back to the ambient `NibSkeleton`'s
  /// `fallbackHeight`.
  final double? height;

  /// Bone box shape.
  final NibSkeletonShape shape;

  @override
  Widget build(BuildContext context) => child;
}

/// Marks [child] as always rendered as-is, loading or not — e.g. a static
/// logo/icon that isn't data-dependent and shouldn't be boned. The ambient
/// `NibSkeleton`'s shader does not recurse into [child] either, so content
/// inside stays real even while everything around it is a bone.
class NibSkeletonIgnore extends StatelessWidget {
  /// Creates a marker that always renders [child] unshaded.
  const NibSkeletonIgnore({super.key, required this.child});

  /// The widget shown unconditionally.
  final Widget child;

  @override
  Widget build(BuildContext context) => child;
}
```

```dart
import 'package:flutter/widgets.dart';

import 'nib_skeleton_types.dart';

/// Resolved bone-fill colours, theme radii, and fallback sizing for one
/// [shadeWidget] call. Internal plumbing — not exported from the package
/// barrel (same convention as `nib_resizable_panels_math.dart`).
class NibSkeletonPalette {
  const NibSkeletonPalette({
    required this.baseColor,
    required this.shimmerColor,
    required this.radiusSm,
    required this.radiusDefault,
    required this.fallbackWidth,
    required this.fallbackHeight,
    required this.boxRadius,
  });

  final Color baseColor;
  final Color shimmerColor;
  final double radiusSm;
  final double radiusDefault;
  final double fallbackWidth;
  final double fallbackHeight;

  /// Caller override for generic box bones' corner radius. `null` means
  /// "use [radiusDefault]" — text-line and circle bones ignore this
  /// entirely (they have their own fixed rule).
  final BorderRadius? boxRadius;
}

/// Builds one bone placeholder box: a coloured, optionally-circular
/// rectangle sized from [width]/[height] (falling back to
/// [NibSkeletonPalette.fallbackWidth]/[fallbackHeight] when unset).
Widget buildBoneBox({
  required NibSkeletonPalette palette,
  double? width,
  double? height,
  NibSkeletonShape shape = NibSkeletonShape.rectangle,
  BorderRadius? radius,
}) {
  final isCircle = shape == NibSkeletonShape.circle;
  return SizedBox(
    width: width ?? palette.fallbackWidth,
    height: height ?? palette.fallbackHeight,
    child: DecoratedBox(
      decoration: BoxDecoration(
        color: palette.baseColor,
        shape: isCircle ? BoxShape.circle : BoxShape.rectangle,
        borderRadius: isCircle
            ? null
            : (radius ?? palette.boxRadius ?? BorderRadius.circular(palette.radiusDefault)),
      ),
    ),
  );
}

/// Recognized leaf widget types → a bone shape sized from the node's own
/// constructor params. Returns `null` when [node] isn't a recognized leaf,
/// so [shadeWidget] can try the next bucket. Implemented in Task 3.
Widget? shadeLeaf(BuildContext context, Widget node, NibSkeletonPalette palette) {
  return null;
}

/// Recognized structural widget types → the same widget type rebuilt with
/// its children individually shaded. Returns `null` when [node] isn't a
/// recognized structural type. Implemented in Task 4.
Widget? shadeStructural(BuildContext context, Widget node, NibSkeletonPalette palette) {
  return null;
}

/// Shades [node] into its bone-loading representation. Called once per
/// build by `NibSkeleton` when `loading: true`.
///
/// Dispatch order: [NibSkeletonIgnore]/[NibSkeletonBone] (explicit author
/// overrides, always win) → [shadeLeaf] → [shadeStructural] → auto-expand
/// any other `StatelessWidget` by calling its own `build(context)` and
/// recursing into the result (Task 5) → a flat fallback bone box for
/// anything else (a `StatefulWidget`, a custom-painted widget, or a
/// `build()` call that threw).
Widget shadeWidget(BuildContext context, Widget node, NibSkeletonPalette palette) {
  if (node is NibSkeletonIgnore) {
    return node.child;
  }
  if (node is NibSkeletonBone) {
    return buildBoneBox(
      palette: palette,
      width: node.width,
      height: node.height,
      shape: node.shape,
    );
  }

  final leaf = shadeLeaf(context, node, palette);
  if (leaf != null) return leaf;

  final structural = shadeStructural(context, node, palette);
  if (structural != null) return structural;

  if (node is StatelessWidget) {
    try {
      final built = node.build(context);
      return shadeWidget(context, built, palette);
    } catch (_) {
      return buildBoneBox(palette: palette);
    }
  }

  return buildBoneBox(palette: palette);
}
```

```dart
const _maxTextBoneWidth = 240.0;

Widget _boneForTextLike(
  BuildContext context, {
  required String? data,
  required InlineSpan? textSpan,
  required TextStyle? style,
  required int? maxLines,
  required NibSkeletonPalette palette,
}) {
  final resolvedStyle = style ?? const TextStyle(fontSize: 14);
  final span = textSpan ?? TextSpan(text: data ?? '', style: resolvedStyle);
  final painter = TextPainter(
    text: span,
    textDirection: Directionality.of(context),
    maxLines: maxLines,
  )..layout();
  final lineHeight = painter.preferredLineHeight;
  final lineCount = maxLines ?? 1;
  final rawWidth = painter.width;
  final width = (rawWidth.isFinite && rawWidth > 0)
      ? rawWidth.clamp(0.0, _maxTextBoneWidth)
      : palette.fallbackWidth;
  final height = lineHeight * lineCount;
  return buildBoneBox(
    palette: palette,
    width: width,
    height: height,
    radius: BorderRadius.circular(height / 2),
  );
}

NibSkeletonShape? _containerShape(Decoration? decoration) {
  if (decoration is BoxDecoration && decoration.shape == BoxShape.circle) {
    return NibSkeletonShape.circle;
  }
  return null;
}

BorderRadius? _containerRadius(Decoration? decoration) {
  if (decoration is BoxDecoration && decoration.borderRadius is BorderRadius) {
    return decoration.borderRadius as BorderRadius;
  }
  return null;
}

Widget _boneForChildlessContainer(Container node, NibSkeletonPalette palette) {
  final decoration = node.decoration;
  final constraints = node.constraints;
  final width = (constraints != null && constraints.hasTightWidth) ? constraints.maxWidth : null;
  final height = (constraints != null && constraints.hasTightHeight) ? constraints.maxHeight : null;
  return buildBoneBox(
    palette: palette,
    width: width,
    height: height,
    shape: _containerShape(decoration) ?? NibSkeletonShape.rectangle,
    radius: _containerRadius(decoration),
  );
}

Widget _boneForChildlessDecoratedBox(DecoratedBox node, NibSkeletonPalette palette) {
  return buildBoneBox(
    palette: palette,
    shape: _containerShape(node.decoration) ?? NibSkeletonShape.rectangle,
    radius: _containerRadius(node.decoration),
  );
}

Widget? shadeLeaf(BuildContext context, Widget node, NibSkeletonPalette palette) {
  if (node is Text) {
    return _boneForTextLike(
      context,
      data: node.data,
      textSpan: node.textSpan,
      style: node.style,
      maxLines: node.maxLines,
      palette: palette,
    );
  }
  if (node is SelectableText) {
    return _boneForTextLike(
      context,
      data: node.data,
      textSpan: node.textSpan,
      style: node.style,
      maxLines: node.maxLines,
      palette: palette,
    );
  }
  if (node is RichText) {
    return _boneForTextLike(
      context,
      data: null,
      textSpan: node.text,
      style: null,
      maxLines: node.maxLines,
      palette: palette,
    );
  }
  if (node is Icon) {
    final size = node.size ?? 24.0;
    return buildBoneBox(
      palette: palette,
      width: size,
      height: size,
      radius: BorderRadius.circular(palette.radiusSm),
    );
  }
  if (node is CircleAvatar) {
    final diameter = node.radius != null
        ? node.radius! * 2
        : ((node.minRadius ?? 20.0) + (node.maxRadius ?? 20.0));
    return buildBoneBox(
      palette: palette,
      width: diameter,
      height: diameter,
      shape: NibSkeletonShape.circle,
    );
  }
  if (node is Image) {
    return buildBoneBox(palette: palette, width: node.width, height: node.height);
  }
  if (node is Container && node.child == null) {
    return _boneForChildlessContainer(node, palette);
  }
  if (node is DecoratedBox && node.child == null) {
    return _boneForChildlessDecoratedBox(node, palette);
  }

    return buildBoneBox(palette: palette, width: node.width, height: node.height);
  }
  return null;
}

```dart
import 'package:flutter/widgets.dart';
import 'package:nib_motion/nib_motion.dart'
    show NibAnim, NibMotion, NibPresence, NibShimmer, NibTransition;

import '../theme/nib_theme.dart';
import 'nib_skeleton_shade.dart';

/// Wraps [child] and, while [loading], renders an automatically-detected
/// bone/skeleton version of it instead of a hand-rebuilt parallel skeleton
/// tree — see `docs/superpowers/specs/2026-07-18-skeleton-design.md` for the
/// detection algorithm.
///
/// ```dart
/// NibSkeleton(
///   loading: isLoading,
///   animated: true,
///   child: ProfileHeader(user: user),
/// )
/// ```
class NibSkeleton extends StatelessWidget {
  /// Creates a skeleton wrapper around [child].
  const NibSkeleton({
    super.key,
    required this.loading,
    required this.child,
    this.animated = false,
    this.transition,
    this.baseColor,
    this.shimmerColor,
    this.fallbackWidth = 80,
    this.fallbackHeight = 16,
    this.borderRadius,
  });

  /// Whether to render the shaded bone tree instead of [child].
  final bool loading;

  /// The real widget tree. Rendered untouched whenever [loading] is false
  /// and [animated] is false.
  final Widget child;

  /// Opt-in `nib_motion`: a shimmer sweep on the bone tree, and an opacity
  /// dissolve when [loading] flips. `false` (default) builds **zero**
  /// `NibMotion`/`NibShimmer`/`NibPresence` widgets — the bone/real tree
  /// swap instantly.
  final bool animated;

  /// Timing/curve for the [animated] dissolve. `null` -> a short ~220ms ease.
  final NibTransition? transition;

  /// The bone fill colour. Defaults to `NibTheme.muted`.
  final Color? baseColor;

  /// The shimmer sweep's highlight colour. Defaults to a slight lightening
  /// of the resolved [baseColor] toward `NibTheme.foreground`.
  final Color? shimmerColor;

  /// Size of the fallback bone box used for any node the detector can't
  /// identify (a `StatefulWidget`, a custom-painted widget, etc).
  final double fallbackWidth;

  /// See [fallbackWidth].
  final double fallbackHeight;

  /// Overrides the default corner radius applied to generic box bones.
  /// Text-line bones (always fully rounded) and `CircleAvatar`-derived
  /// bones (always circular) ignore this.
  final BorderRadius? borderRadius;

  NibTransition get _transition =>
      transition ?? const NibTransition(duration: Duration(milliseconds: 220));

  NibSkeletonPalette _palette(BuildContext context) {
    final theme = NibTheme.of(context);
    final resolvedBase = baseColor ?? theme.muted;
    final resolvedShimmer =
        shimmerColor ?? Color.lerp(resolvedBase, theme.foreground, 0.12)!;
    return NibSkeletonPalette(
      baseColor: resolvedBase,
      shimmerColor: resolvedShimmer,
      radiusSm: theme.radiusSm,
      radiusDefault: theme.radiusDefault,
      fallbackWidth: fallbackWidth,
      fallbackHeight: fallbackHeight,
      boxRadius: borderRadius,
    );
  }

  @override
  Widget build(BuildContext context) {
    if (!animated) {
      if (!loading) return child;
      return IgnorePointer(
        child: shadeWidget(context, child, _palette(context)),
      );
    }

    final palette = _palette(context);
    final bone = IgnorePointer(
      child: NibShimmer(
        enabled: true,
        baseColor: palette.baseColor,
        shimmerColor: palette.shimmerColor,
        child: shadeWidget(context, child, palette),
      ),
    );

    return NibPresence(
      children: [
        if (loading)
          NibMotion(
            key: const ValueKey('nib-skeleton-bone'),
            initial: const NibAnim(opacity: 0),
            animate: const NibAnim(opacity: 1),
            exit: const NibAnim(opacity: 0),
            transition: _transition,
            child: bone,
          )
        else
          NibMotion(
            key: const ValueKey('nib-skeleton-content'),
            initial: const NibAnim(opacity: 0),
            animate: const NibAnim(opacity: 1),
            exit: const NibAnim(opacity: 0),
            transition: _transition,
            child: child,
          ),
      ],
    );
  }
}
